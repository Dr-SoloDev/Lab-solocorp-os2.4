# สำเร็จแล้ว จริงหรือ? — V2

สถานะ: internal review; ตัวอย่างจำลองทั้งหมด; ไม่ใช่หลักฐาน incident จริง

## ฉาก 1: สำเร็จแล้ว / จริงหรือ?
ภาพ: status
เสียง:
หน้าจอขึ้นว่าสำเร็จ
แต่งานเสร็จจริงหรือยัง?
ลองดูว่าไฟเขียวนี้ยืนยันอะไร

## ฉาก 2: รับงานแล้ว / ยังไม่ใช่คำตอบ
ภาพ: split
เสียง:
ระบบอาจรับงานเข้าคิวแล้ว
แต่โมเดลยังไม่ส่งคำตอบกลับมา
สองสถานะนี้ต้องตรวจแยกกัน

## ฉาก 3: ลองเรียกจริง / ตรวจคำตอบด้วย
ภาพ: probe
เสียง:
ตรวจชื่อผู้ให้บริการกับชื่อโมเดล
ส่งคำขอทดสอบหนึ่งครั้ง
แล้วตรวจว่าคำตอบตรงกับที่คาดไว้หรือไม่

## ฉาก 4: เก็บหลักฐาน / ให้ตามกลับได้
ภาพ: evidence
เสียง:
เก็บทั้งชื่อโมเดล เวลา และคำขอ
พร้อมคำตอบ หรือรายละเอียดเมื่อเกิดข้อผิดพลาด
ให้คนอื่นเปิดตรวจซ้ำได้

## ฉาก 5: เรียกไม่ได้ / ต้องมองเห็น
ภาพ: alert
เสียง:
ถ้าเรียกไม่ได้ ให้แสดงข้อผิดพลาดตรง ๆ
แจ้งเจ้าของงาน พร้อมหลักฐานที่ตามกลับได้
แล้วตรวจซ้ำหลังแก้ไข

## ฉาก 6: ขอดูหลักฐาน / ก่อนเชื่อผล
ภาพ: question
เสียง:
ความน่าเชื่อถือเริ่มจากผลที่ตรวจได้
วันนี้ เอเจนต์ของคุณมีหลักฐานอะไร
ให้คนอื่นตรวจซ้ำได้บ้าง?
