# ฟิล์ม — Final Video Script: Model Health Check
> **Duration:** 90 seconds
> **Core message:** ยืนยันสุขภาพของโมเดลด้วยการเรียกจริงและหลักฐาน

| Time | Visual scene | Voiceover / Audio |
|:--|:--|:--|
| 0-15s | Hook — หน้าจอสถานะสีเขียว มีเคอร์เซอร์กะพริบตรงคำว่า SUCCESS? ก่อนเส้นเชื่อมโมเดลจะดับ | VO: "หน้าจอขึ้นว่าสำเร็จ แต่เคยตรวจไหมว่าโมเดลตอบกลับจริง หรือมีแค่ระบบรายงานว่าเรียบร้อย?" BGM: เปิดด้วย pulse เบา ๆ แล้วเว้นจังหวะ |
| 15-30s | Internal note — แผงบันทึกงานภายใน แสดง Model A และ Model B เป็นช่องเตือน โดยไม่แสดงชื่อจริงหรือข้อมูลส่วนตัว | VO: "ในบันทึกงานภายในของเรา เคยพบชื่อโมเดลที่ใช้ไม่ได้สองรายการ แต่รายงานยังขึ้นว่าสำเร็จ เรื่องนี้ยังต้องตรวจหลักฐานเพิ่ม" BGM: pulse สั้นสองครั้ง แล้วลดระดับ |
| 30-45s | The gap — เส้นทาง request ไปถึง gateway แต่ปลายทางไม่ตอบ; ฝั่ง orchestration ยังเป็นสีเขียว ฝั่ง endpoint เป็นสีแดง | VO: "เพราะระบบรับคำสั่งสำเร็จ ไม่ได้แปลว่าปลายทางยังพร้อมใช้ และไม่ได้ยืนยันว่า agent ทำงานครบ" BGM: low tone ค้างสั้น ๆ |
| 45-60s | Evidence — การ์ด provider, model, request, response และ exit status เรียงต่อกันเป็นหลักฐาน | VO: "เริ่มจากตรวจ provider กับชื่อ model แล้วทดลองเรียกจริง เก็บ request, response และ exit status ทุกครั้ง" BGM: จังหวะชัดขึ้นตามการ์ด |
| 60-75s | Alert target — หน้าปัดเวลาหกชั่วโมงติดป้าย DESIGN TARGET; สัญญาณเตือนเกิดเมื่อ health check ล้มเหลว | VO: "ตั้ง health check ให้เห็นความผิดปกติเร็ว เป้าหมายคือเตือนภายในหกชั่วโมง ไม่ใช่ SLA ที่อ้างว่าเปิดใช้อยู่แล้ว" BGM: rising tone เบา ๆ แล้วคลี่คลาย |
| 75-90s | Human review — รายงานหลักฐานถูกส่งให้คนตรวจ ก่อนวงจร agent เริ่มรอบใหม่ | VO: "ถ้าคุณสร้าง agent อย่าหยุดที่คำว่า success ลองเรียกจริง เก็บหลักฐาน แล้วค่อยเชื่อผล" BGM: ปิดด้วย note เดียวและปล่อยเงียบ |

## Production Notes
- ภาพทุกฉากเป็น procedural graphics ที่สร้างในเครื่อง ไม่มี stock footage หรือโลโก้บุคคลที่สาม
- ซับเป็นระดับฉากตามบทพากย์ ไม่ใช่ word-aligned karaoke
- ข้อกล่าวอ้างเรื่องชื่อโมเดลสองรายการมาจากบันทึกภายในที่ผู้ใช้ให้ และยังไม่ได้ตรวจจากแหล่งอิสระ
- กรอบแจ้งเตือนหกชั่วโมงเป็น design target ไม่ใช่ SLA หรือสถานะ production
- สถานะเสียง: internal review draft; ตรวจสิทธิ์เสียงก่อนนำไปใช้นอกทีม
