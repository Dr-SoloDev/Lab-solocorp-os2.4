# EP01 — จาก Brief ถึงปุ่มเผยแพร่

## เป้าหมาย

> **Duration:** 90 seconds

- แนะนำวิธีทำงานของแผนก Content Creator ผ่านงานหนึ่งชิ้น ตั้งแต่รับ brief จนถึงจุดตรวจเผยแพร่
- คนดูหลัก: ครีเอเตอร์และทีมเล็กที่อยากเห็นว่า AI ช่วยทำคอนเทนต์อย่างไรโดยยังมีคนรับผิดชอบ
- รูปแบบ: วิดีโอแนวตั้ง 9:16, 90 วินาที, motion graphic กับ voiceover ภาษาไทย, ไม่ใช้ talking head
- โทน: ตรงไปตรงมา ลงมือทำจริง ยอมรับข้อจำกัด ไม่อ้างว่าระบบพร้อมทุกกรณี
- หมายเหตุ: โปรเจกต์ตั้งต้นกำหนดคลิป TikTok ไว้ 15–60 วินาที แต่คำขอนี้กำหนด 90 วินาที จึงวางเป็นวิดีโอเปิดตัวแนวตั้ง ไม่ระบุแพลตฟอร์ม

## กำกับภาพและเสียง

- ใช้ local Content MCP renderer สร้างฉากสามมิติแบบ procedural; ให้หัวข้อฉากและซับไทยสื่อสารชื่อบทบาทและจุดตรวจ
- Render draft นี้ไม่ฝังสติกเกอร์ Turbo/Meetoo; ใช้หน้าจอและการ์ดจำลองแทน เพื่อให้อยู่ในเส้นทาง synthetic-only ที่รองรับ
- ใช้เสียงคลิกกระดาษและเสียงเปลี่ยนฉากแบบสั้น ๆ; ยังไม่ระบุเพลงจนกว่าจะยืนยันสิทธิ์
- ซับไทยอ่านได้ขณะปิดเสียง จำกัดไม่เกิน 2 บรรทัดต่อเฟรม และเว้นพื้นที่ UI ของแพลตฟอร์ม

## หลักฐานและขอบเขตคำกล่าวอ้าง

- รายชื่อและหน้าที่ทั้งห้าบทบาทตรวจจาก Content MCP department info เมื่อ 2026-11-02; โปรไฟล์แผนกตรวจย้อนกลับได้ที่ commit git 19b5e59
- ตัวอย่าง Publish Gate ที่หยุดงานเพราะ source verification และสิทธิ์ยังไม่ครบ อ้างจาก runbook วิดีโอ 90 วินาทีของ SoloCorp OS
- แสดงภาพหน้าจอจริงแบบครอปให้เห็นเฉพาะรายชื่อบทบาท ห้ามติด path, รหัส campaign, ข้อมูลส่วนตัว หรือรายละเอียดภายในที่ไม่จำเป็น
- เรียกงานนี้ว่า “ร่าง/ช่วงทดลอง” ห้ามกล่าวว่าแผนกผ่านการรับรองครบทุกด่าน หรือปล่อยงานได้อัตโนมัติ
- ที่มาสติกเกอร์เป็น asset ภายในโปรเจกต์; ต้องยืนยันสิทธิ์เสียง ภาพ และฟอนต์ก่อนเผยแพร่สู่สาธารณะ
