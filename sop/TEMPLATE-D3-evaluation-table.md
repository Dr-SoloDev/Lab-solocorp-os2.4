## กฎการกรอก
1. **ทุกแถวต้องมีตัวเลข/ผลจริง** — ห้ามคำอธิบายลอยๆ
2. **failure ทุกอันต้องมี root cause** — "พังเพราะอะไร" ห้ามเว้น
3. **ห้ามลบงานที่ล้มเหลวออกจากตาราง** (no cherry-picking)
4. หลักฐานแต่ละแถว = path/ลิงก์ที่เปิดดูได้จริง
