# RFC

Create or review RFC (Request for Comments) for governance decisions.

## Usage
```
/rfc-new <title> <summary> <action>
```

Actions: `create`, `review`, `approve`, `reject`

## Example
```
/rfc-new "CI/CD Migration" "Migrate from Jenkins to GitHub Actions" create
```
