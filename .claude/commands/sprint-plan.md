# Sprint Plan

Request a sprint plan template or report progress for any department.

## Usage
```
/sprint-plan <department> <sprint> <action>
```

Actions: `plan` (request template), `report` (update progress), `status` (dashboard)

## Example
```
/sprint-plan coo "Sprint 2" plan
```
