# Daily Ops

Generate daily operations status report, route requests, or check SOP compliance.

## Usage
```
/daily-ops <action>
```

Actions: `status` (ops report), `route` (ส่ง request), `sop` (ตรวจ compliance)

## Example
```
/daily-ops status
```
