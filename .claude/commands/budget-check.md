# Budget Check

Check budget status, run cost analysis, or project ROI for any department.

## Usage
```
/budget-check <department> <period> <action>
```

Actions: `check` (ดูงบ), `analyze` (วิเคราะห์ cost), `project` (ROI)
Periods: `monthly`, `quarterly`, `ytd`

## Example
```
/budget-check engineering quarterly check
```
