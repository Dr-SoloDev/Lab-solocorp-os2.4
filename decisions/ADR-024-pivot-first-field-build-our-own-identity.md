## บริบท

ADR-022/023 วางสนามแรกไว้แบบ: **ช่วยครีเอเตอร์ภายนอก** (Owner + ลูกศิษย์) ลุ้นรางวัล X

## การตัดสินใจ

### 1. ช่องทาง = X เป็นหลัก (เจาะกว้าง + เอาไปลงแพลตฟอร์มอื่นได้)
- ไม่ผูกกับโปรแกรมรางวัลอีกแล้ว → ข้อจำกัด "must be yours / ไม่ mass-produced" ของ Bonus ไม่ผูกกับเรา
- เนื้อหา 9:16 เดียวกันใช้ได้ทั้ง X · TikTok · Reels · Shorts → **เราเป็นเจ้าของสื่อ ไม่ต้องผูกกับแพลตฟอร์มใด**
- ยังคงใช้เงื่อนไขที่ดีไว้ (9:16 · <3 นาที · ไม่มีลายน้ำ · ไม่ลบโพสต์) เพราะมันดีกับทุกแพลตฟอร์ม

### 2. ครีเอเตอร์คนแรก = Dr.Solodev เอง
โปรไฟล์ `creator.dr-solodev.profile` (4 ท่อน + ตลิ่งโทน `จริงใจ · ชัด · มือช่าง`)

### 3. ⭐ เนื้อหา = **ขุดจากงานจริงใน repo** (ไม่คิดขึ้นเอง)
`solocorp_skills/worklog.py` ขุดจาก 4 แหล่ง:

| แหล่ง | ได้ |
|:--|:--|
| `decisions/ADR-*.md` | บริบท (ปัญหา) → การตัดสินใจ (แก้) → ผลกระทบ (เพื่ออะไร) |
| `brain/session-log.md` | งานรายวัน + Owner Request |
| `git log` | commit ที่แก้ปัญหาจริง |
| `bus/evidence/*.json` | เคสที่พังแล้วแก้ (expected/actual จริง) |

**กฎ: เรื่องที่มี "รอยแผลจริง" + "เพื่ออะไร" เท่านั้นที่ถูกหยิบมาเล่า** (vision §5.2, §6)

### 4. 2 รูปแบบเนื้อหา (ไม่ใช่คลิปอย่างเดียว)
- **คลิปแนวตั้ง** (9:16) — มีเสียงพูดไทย + ซับไตเติล (`scripts/make_clip.py`)
- **โพสต์ข้อความ** — สไตล์ประกาศเรซูเม่: `เจอปัญหา / แก้ / เพราะ / หลักฐาน` + ลายเซ็น

โมเดล B (`creator_daily`) เลือกโหมดให้อัตโนมัติ: **worklog ก่อน** → ถ้าไม่มีค่อยใช้ข่าว + 4 ท่อน

### 5. ทุกวัน = ลงอะไรสักอย่าง
ตัว tracker เดิมนับ "posting days ตาม Pacific Time" — เปลี่ยนความหมายเป็น **วินัยโพสต์ทุกวัน** (ไม่ผูกกับรางวัล)
วิธีโพสต์ที่ปลอดภัย: **หลัง 15:00 ไทย** = วัน PT ตรงกับวันไทยเสมอ

## ผลกระทบ

**✅ ดี**
- เนื้อหา **ไม่มีวันหมด** — ทุกวันที่เราทำงานมีเรื่องเล่าได้ 1 เรื่อง (วันนี้ขุดได้ 8 เรื่องจาก 14 วัน)
- เนื้อหา **จริงและพิสูจน์ได้** (มีหลักฐาน/ตัวเลข/เทสต์) → ตรงกับ vision "สายสร้างตัวตนวัดซื่อสัตย์"
- **หลุดข้อจำกัดของโปรแกรมรางวัล** — เราโพสต์อะไรก็ได้ (แค่ต้องไม่ผิดกฎ X ทั่วไป)
- ไม่ต้องรอ invite · ไม่ต้องมี Premium/Stripe (ถ้าจะไม่ลุ้นรางวัล)
- ทำให้ **หมุด 4 พิสูจน์ตัวเอง** — SoloCorp คือตัวอย่างที่ทำงานจริง ไม่ใช่กรณีศึกษา

**⚠️ ต้องระวัง**
- **AI-made clip** ยังผิดกฎ X ทั่วไปเรื่อง AI media → ต้อง label / ใช้เสียงคนจริง
- ความสม่ำเสมอคือทุนของตัวตน — ข้ามวัน = พังจุดตัวตน (ไม่ใช่แค่พลาดรางวัล)
- ต้องมี "gate" ก่อนโพสต์จริง: **คนอ่าน/อนุมัติ** (เรายัง publish เอง ไม่กดแทน)
- เนื้อหาเป็นเรื่องงานจริง → ต้องระวังข้อมูลที่ไม่ควรเปิด (คีย์, ชื่อลูกค้า, รายได้)

**🔄 ยังไม่ทำ**
- ต่อ X จริง (โพสต์อัตโนมัติ/เตรียม draft) — เสี่ยงข้อ "unauthorized automation" ในโปรแกรมรางวัล (ถ้าไม่ลุ้นรางวัล ก็ยังเสี่ยงนโยบายทั่วไป → แนะนำให้คนกดเอง)
- การออกแบบ "โพสต์ข้อความ" ให้เป็นซีรีสจริง (ตอนนี้เป็น template เดียว)
- แผนหลายแพลตฟอร์ม (ตอนนี้ผลิต 9:16 ก้อนเดียว ใช้ได้หลายแพลตฟอร์มแล้ว แต่ยังไม่มี preset ต่าง)
