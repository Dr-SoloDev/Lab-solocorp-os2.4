# 🎬 Creator Kit — สนามแรก: ครีเอเตอร์สายสร้างตัวตน (TikTok)

> สนามแรกของ SoloCorp (หมุด 4) — คิดไอเดีย → เขียนสคริปต์ → เตรียมลง TikTok
> อ้างอิง: `brain/vision-small-people-20261015.md` §5.2–5.6 (LOCKED) · `decisions/ADR-022-first-field-creator-kit.md`

## เมื่อไรใช้

- ครีเอเตอร์ (เจ้าของร้าน / ครู / เกษตรกร / ฟรีแลนซ์) อยากให้ช่วยสร้างคอนเทนต์
- มีโปรไฟล์ครีเอเตอร์อยู่แล้ว แล้วอยากได้ไอเดีย/สคริปต์ชุดใหม่

## 4 ท่อน — ถามแบบน้ำ (เปิด ไม่ใช่ ABCD)

ถามทีละข้อ ใช้ภาษาชาวบ้าน อย่าใช้ศัพท์เอเจนต์

| # | ท่อน | ถามว่า | ตัวอย่างคำตอบ |
|:--|:--|:--|:--|
| 1 | **ตัวตน** | คุณเป็นใคร — แล้วตอนนี้ทำอะไรอยู่? | "ฉันเป็นคนทำ [งาน] — ตอนนี้กำลัง [ทำอะไร]" |
| 2 | **รอยแผล** | ตอนนี้ทำได้ดีกว่าตอนเริ่มยังไง — เคยล้มเหลวมากี่รอบ? | "ตอนแรก [ล้มเหลว] … ตอนนี้ [อะไรเปลี่ยน]" |
| 3 | **คนดู** | อยากให้ใครเห็นเรื่องนี้ — เขาติดอะไรอยู่? | "อยากให้ [คนกลุ่ม] ที่กำลัง [ปัญหา] เห็นว่า [ทางออก]" |
| 4 | **เหตุผลที่ยังทำ** | ถ้าไร้เงิน 0 บาท — ยังทำต่อทำไม? | "เพราะ [อยากเป็น/อยากให้เห็น]" |

**+ ตลิ่งโทน 3 คำ** — เจ้าของเลือกเอง: `เช่น ชัดซื่อ / มือช่าง / เรียบง่าย`

> ⚠️ ท่อน 2+3 = **สะพานเชื่อมคน 2 ฝั่ง** (ฝั่งที่มีของดีแต่คนไม่เห็น ↔ ฝั่งที่มองหาของดีแต่หาไม่เจอ)
> ถ้าคำตอบท่อน 2 ยังไม่มี "ล้มเหลว" หรือท่อน 3 ยังไม่ชัดว่าใคร → **ถามซ้ำก่อนไปต่อ**

## ขั้นตอน

### 1 · เก็บโปรไฟล์
```python
from solocorp_skills.creator import CreatorProfile, upsert_profile, slugify

p = CreatorProfile(slug=slugify("ฟรีแลนซ์ตัดต่อคลิป"), name="โชค",
                   tubean={"tubean": "...", "roeyphae": "...", "khondu": "...", "hettai": "..."},
                   tone_words=["ชัดซื่อ", "มือช่าง", "เรียบง่าย"])
upsert_profile(p)
print(p.is_complete(), p.missing())   # ต้อง True / []
```

### 2 · คิด 10 ไอเดีย (ตัวช่วยคิดไอเดีย)
ใช้ 2 แหล่งรวมกัน:
- **เทรนด์/ข่าว** → `web_search` (ดู `@solocorp/engineering/web-read`) หรือ `news_daily`
- **เรื่องจริงของครีเอเตอร์** → จากท่อน 2 (รอยแผล) — นี่คือวัตถุดิบที่หาไม่ได้จากเว็บ

ทุกไอเดียต้องตอบได้ 2 ข้อ: **ทำไมถึงตรงกับท่อน 3 (คนดู)** และ **ใช้ท่อน 2 (รอยแผล) ตรงไหน**

### 3 · เขียนสคริปต์ (ตัวช่วยออกแบบสคริปต์)
```python
from solocorp_skills.creator import build_script
script = build_script(p, {"title": "...", "why": "..."}, caption="...", hashtags=[...])
```
โครงคลิป TikTok — 4 ท่อน → 4 จังหวะเวลา:

| ท่อน | จังหวะ | เวลา |
|:--|:--|:--|
| ตัวตน | hook | 0–3 วิ |
| รอยแผล | เนื้อหาหลัก | 3–30 วิ |
| คนดู | หันมาหาคนดู | 30–45 วิ |
| เหตุผลที่ยังทำ | ปิด + CTA | 45–55 วิ |

### 4 · ออกแพ็กเกจ
```python
from solocorp_skills.creator import build_package
build_package(p, script, Path("bus/media/creator/<slug>/<วันที่>/"))
```
ได้ 5 ไฟล์: `.script.md` `.shots.md` `.caption.md` `.origin.md` `.checklist.md`

### 4b · ทำคลิปจริง (ถ้าต้องการ)
```bash
python scripts/make_clip.py --script <xxx.script.md> --out <xxx.mp4>
```
→ mp4 **1080x1920** พร้อมเสียงพูดไทย + ซับไตเติล (piper + ffmpeg/libass) แล้วตรวจเงื่อนไขโปรแกรมให้อัตโนมัติ
ติดตั้งเสียงครั้งแรก: `scripts/setup_tts.sh`
รายละเอียดทั้งหมด: `docs/MEDIA-TOOLKIT.md`

> ⚠️ **คลิปที่เสียงสังเคราะห์ = ไม่นับในโปรแกรม X** — ครีเอเตอร์ต้องพูด/ถ่ายเอง
> เครื่องมือชุดนี้เหมาะกับ "ครีเอเตอร์ถ่ายเอง เราช่วยคิด+เขียน+ตัด+ซับ"

### 5 · เตรียมลง TikTok (แบบ draft — คนกดยืนยัน 1 คลิก)
ใช้ `stealth-browser` (Chrome จริง เก็บ cookie ได้):
```
spawn_browser → navigate(tiktok.com/upload) → file_upload(วิดีโอ 1080x1920)
→ type_text(caption) → กด "Save as draft" → แจ้งเจ้าของให้กด Publish
```
> ⚠️ **ห้ามกด Publish เอง** — Owner ตัดสินใจ "draft + กดยืนยัน 1 คลิก" (2026-10-20)
> วิดีโอต้อง 1080x1920 (media_pipeline preset `reels`)

### 6 · นับผลเอง
อ่านหน้าโปรไฟล์/creator dashboard ผ่าน `stealth-browser` (login แล้ว) → เขียนลง facts
```
key = "creator.<slug>.stats.<วันที่>"
metadata: {workstream: "OWN-BIZ", sensitivity: "INT"}
```

## โปรแกรม X Video Kickstart Bonus (ถ้าเข้าร่วม)

เงื่อนไขจริงจาก **Terms ทางการ** (Terms คุมเหนือ Help Page) — ดู ADR-023

| เงื่อนไข | ค่า |
|:--|:--|
| คลิปที่นับ | แนวตั้ง **9:16** · **< 3 นาที** · **ของครีเอเตอร์เอง** · ไม่มีลายน้ำ · ไม่ใช่ branded/paid |
| เป้าหมาย | **15 คลิป บน 15 วันที่แตกต่างกัน** (ตาม **Pacific Time**) ภายใน ~30 วัน |
| รอบแรก | 15 ต.ค. – 14 พ.ย. 2026 (PT) · enroll deadline **30 ต.ค. 23:59 PT** |
| ได้ | $1,000–$5,000 (ตาม follower tier) + **Premium+ ฟรี 1 ปี** + fast-track OCR |

**🚫 ข้อห้ามจาก Terms §4(a) — อันนี้ทำให้พลาดทั้งรอบ**
- **AI ทำคลิปให้ = ไม่นับ** ("must be yours" + "not mass-produced")
- **โพสต์อัตโนมัติ = เสี่ยง** ("not posted solely through unauthorized automation")
- คลิปซ้ำ/ใกล้เคียงกัน = นับแค่ 1 · ลบ/ทำ protected = หลุดนับ
- โพสต์ต้องคงอยู่ (public + ไม่แก้) **อีก 30 วันหลังจบรอบ**

**บทบาทของเรา = ผู้เตรียม · ผู้ตรวจ · ผู้จัดการเวลา** (ไม่ผลิตคลิป ไม่กดโพสต์แทน)

```python
from solocorp_skills.programs.x_kickstart import (
    PostingTracker, check_video, clip_checklist_md, safe_posting_window_th)

t = PostingTracker(creator="slug").load()
print(t.status())              # วันนี้โพสต์แล้วไหม / เหลือกี่วัน / เก็บโพสต์ถึงเมื่อไร
print(safe_posting_window_th())  # ('15:00', '23:59') ← โพสต์หลัง 15:00 ไทย = วัน PT ตรงกัน
print(check_video("clip.mp4"))   # ตรวจ 9:16 + <3 นาที ด้วย ffprobe
```

> ⏰ **Pacific Time:** ไทย = PT + 15 ชม. → โพสต์ตี 2-3 ทุ่มไทย = นับเป็น**เมื่อวาน** ตาม PT → กินวันของเมื่อวานทิ้งเปล่า
