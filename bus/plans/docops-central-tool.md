## 3. สถาปัตยกรรมเครื่องมือกลาง (3 ขา)
| ขา | หน้าที่ | เครื่องมือ | ตัวอย่าง |
|:---|:---|:---|:---|
| ขาเข้า (อ่าน) | อ่าน TOR/บิล/สัญญาที่ลูกค้าส่งมา → ข้อมูลโครงสร้าง | Docling (ติดตั้งแล้ว ✅) | TOR สแกน → เทียบ template เรา → เจอจุดเสี่ยงก่อนเซ็น |
| คลังกลาง (เก็บ) | Template + ข้อกำหนดมาตรฐานใช้ซ้ำ | คลัง template (ยังไม่สร้าง) | สัญญาจ้าง, NDA, ใบเสนอราคา... |
| ขาออก (สร้าง) | ผสม template + ข้อมูลงาน → เอกสารพร้อมส่ง | Papernova (มีโค้ด ยังไม่เสร็จ) | ใบเสนอราคา, สัญญา, ใบแจ้งหนี้, ใบเสร็จ |

## 4. คลัง template ที่ต้องสร้าง (ตามลำดับ)
1. สัญญาจ้างทำของ/บริการ (ตัวแม่ — สโคป, ค่าจ้าง, กำหนดส่ง, แก้ไขงาน, ความรับผิด) ← ทำก่อน
2. เอกสารขอบเขตงาน (ทำอะไร / ไม่ทำอะไร)
3. ใบเสนอราคา + เงื่อนไข
4. NDA
5. ใบส่งมอบ + ตรวจรับงาน
6. ใบแจ้งหนี้ / ใบเสร็จ
