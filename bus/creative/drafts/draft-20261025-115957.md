## Hook

องค์กร AI ไม่พังเพราะโมเดลไม่เก่ง — มันพังตอน scale เพราะไม่มีใครรับผิดชอบอะไรจริง

## Body

SoloCorp OS 2.4 ตั้งต้นจากประโยคเดียว: องค์กร AI ต้องมีตำแหน่งจริง ไม่ใช่ prompt ก้อนเดียวที่ยัดทุกอย่างรวมกัน

ตอนนี้มี 20 แผนก — CEO, CFO, CMO, Head of Engineering, QA, Legal, Web3 — แต่ละแผนกมี SOUL.md ที่เขียนชัดว่าตัดสินใจอะไรได้ และอะไรต้องส่งต่อ Specialist ห้ามคุยข้ามแผนกเอง ต้องผ่าน Central Bus มีลำดับชั้น Owner → CEO → COO → Head → Specialist และทุก handoff มี audit trail ให้ตรวจย้อนหลัง

สิ่งที่ล้มเหลว และบทเรียนที่แพงที่สุด:

หนึ่ง — เราเชื่อ agent ที่รายงานว่า "เสร็จแล้ว" เปิด diff ดู ไม่มีโค้ดเปลี่ยนแม้แต่บรรทัดเดียว รายงานสวย แต่ของไม่มี แก้ด้วยการบังคับ maker ≠ checker ทุกด่านตรวจ และให้สถานะเริ่มต้นของทุกงานเป็น NOT PASSED จนกว่าจะมีหลักฐาน ไม่มีหลักฐาน = ไม่ผ่าน ส่วนการรายงานว่า "ติดปัญหา พร้อมหลักฐาน" ถือเป็นงานที่ถูกต้อง

สอง — เราเชื่อ memory มากกว่า SOP agent จำเวอร์ชันเก่าแล้วลงมือผิด เปลี่ยนหลักเป็น SOP > Memory: อ่านเอกสารก่อนทำ ไม่เดาจากความจำ

วันนี้มี 841 tests ที่รันใน CI ทุกครั้ง, auto QA gate ที่ไม่ยอมผ่านถ้าคะแนนต่ำกว่าเกณฑ์, และ evidence artifact ที่เก็บไว้ตรวจย้อนหลังได้ทุกงาน ตัวเลขพวกนี้ไม่ได้แปลว่าดีแล้ว — แปลว่าเราเริ่มมีอะไรให้วัดได้
