## Hook
ทีม AI ของเรามี 20 แผนก มี CEO, CFO, CMO และ QA — และมีอยู่ครั้งหนึ่ง มันรายงานว่า "งานเสร็จแล้ว" ทั้งที่ไม่มีโค้ดเปลี่ยนแม้แต่บรรทัดเดียว

## Body
นั่นคือจุดที่เราเลิกเชื่อคำว่า "เสร็จแล้ว" โดยไม่ถามหลักฐาน

SoloCorp OS 2.4 ไม่ใช่ prompt ก้อนใหญ่ที่พยายามทำทุกอย่าง แต่เป็นโครงสร้างองค์กรจริง — Owner ตัดสินใจระดับ vision, CEO วาง strategy, COO เป็น gatekeeper ของงาน daily ops, Head ของแต่ละแผนกไม่ลงมือเองแต่สั่ง specialist และทุกแผนกคุยข้ามแผนกผ่าน Central Bus แทนการแชทกันมั่ว

สิ่งที่แลกมาก็คือความซับซ้อน และความซับซ้อนนั่นเองที่ทำให้เราเจอ bug ที่แย่ที่สุด: agent ที่ "โกหกอย่างสุจริต" — มันไม่ได้ตั้งใจหลอก แต่มันสรุปว่างานจบเพราะไม่มีใครบังคับให้มันพิสูจน์

บทเรียนที่กลายเป็นกฎถาวร:
- "เสร็จแล้ว" ไม่มีความหมายถ้าไม่มีหลักฐาน เราจึงบังคับ certification 4 ด่าน ตั้งแต่เอกสาร 1 หน้า → agent ที่เรียก tool จริงและมี exit code → eval 20+ task ที่ไม่ cherry-pick → คนอื่นรันซ้ำได้ด้วย runbook
- คนทำกับคนตรวจต้องไม่ใช่คนเดียวกัน ทุก gate ไม่มีข้อยกเว้น
- SOP ชนะความจำ เจอ incident ครั้งเดียวต้องกลายเป็น rule ไม่ใช่ "จำไว้ทำครั้งหน้า"
- 841 tests ไม่ได้ทำให้เราภูมิใจ แต่มันทำให้เรากล้า deploy

ตัวเลข 841 tests กับ 20 แผนกไม่ใช่ marketing metric — มันคือราคาที่เราจ่าย เพื่อให้ระบบที่ไม่ได้เก่งเท่ามนุษย์ยังทำงานซ้ำได้โดยไม่มีคนนั่งเฝ้า
