มุมผมดูแล routing + heartbeat ของ Bus — สองเรื่องนี้ผูกกัน ต้องคิดพร้อมกัน

1) เรื่อง X-API-Key: client ที่ยิงเข้า Bus ไม่ได้มีแค่ 3 loops — workers/agents, govctl, MCP ก็ยิงอยู่ ถ้าไม่สแกนขาเข้าทั้งหมดจะ 401 ตอน cron ยิงจริง ซึ่งไม่มีมนุษย์คอยดู เสนอให้ heartbeat เก็บตัวนับ 401 ไว้ด้วย เป็นสัญญาณเตือนก่อนหมด heartbeat

2) เรื่อง canonical path: อย่าทำแค่เปลี่ยนชื่อ ให้เป็น symillion จุดเดียวแล้วให้ cron + config + เอกสารอ้างชี้เดียวกัน ไม่งั้นจะกลายเป็นสอง source of truth แล้วตามหลักของผมเอง

3) ลำดับ: manual 1 รอบก่อนตั้ง cron 30 นาที ตามแผนนั้นถูกแล้ว เพราะถ้า auth พังตอน cron เท่านั้น จะเจ
